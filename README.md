## TP3 NLP : TF-IDF et BERT

Le TP3 porte sur le traitement automatique du langage naturel avec deux approches principales :

- TF-IDF pour représenter les textes à partir de l'importance des mots.
- BERT pour transformer les phrases en embeddings contextuels.
- Comparaison des performances entre TF-IDF et BERT sur un dataset réel de critiques de films.
